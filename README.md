# Borderless Mining — Switch Windows Without Freezing Your Game

Borderless Mining 9minecraft Mod changes standard fullscreen mode into a borderless windowed mode. It fills your entire monitor screen without showing window frames or title bars. You can switch between your game and other programs like web browsers, music apps, or chat windows without waiting. It stops the black screen flickering that normally happens when you switch tasks on your computer.

Turns normal fullscreen mode into a borderless window that covers your entire display.

## What this build is

An unofficial rebuild of **comp500**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
